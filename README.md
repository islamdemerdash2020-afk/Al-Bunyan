# البنيان للتشطيبات العامة — نظام إدارة الشركة

تطبيق عربي (RTL) في ملف HTML واحد: العملاء، المشروعات، المقايسات، المقبوضات والمصروفات، العهد، الموردون، الحسابات الختامية، لوحة تحليلية، كشوف الحساب وتقارير PDF/Excel.

## هيكل المستودع
- `index.html` — التطبيق كاملاً (النسخة المنشورة على Claude).
- `docs/user-guide.pdf` — دليل شرح النظام.
- `desktop-icon/` — مثبّت أيقونة سطح المكتب (Windows).
- `CHANGELOG.md` — سجل التعديلات.

## وضع الاستضافة المستقلة (Vercel / GitHub Pages)
الملف يعمل في مكانين:
- **داخل Claude:** البيانات في قاعدة بيانات Claude وتُشارَك بين الأجهزة والمستخدمين.
- **على Vercel أو أي استضافة:** يكتشف النظام غياب Claude ويعمل تلقائيًا بوضع مستقل، وتُحفظ البيانات في متصفح **هذا الجهاز فقط** (IndexedDB).

تنبيهات الوضع المستقل:
- لا مشاركة للبيانات بين الأجهزة أو المستخدمين، وكل متصفح له بياناته. مسح بيانات المتصفح يمسحها، فخذ نسخة احتياطية دورية (الإعدادات › تنزيل نسخة كاملة).
- كلمة المرور حماية من واجهة الصفحة فقط ولا تمنع من يملك الجهاز نفسه من قراءة بياناته.
- لا تضع عليه بيانات عملاء حقيقية قبل ربطه بقاعدة بيانات خادمية، ولا تتركه علنيًا بدون حماية.
- ميزة التحليل بالذكاء الاصطناعي غير متاحة خارج Claude.

لا ترفع ملفات النسخ الاحتياطية (backup-*.json) على GitHub لأنها بيانات عملاء.

## تعديل ورفع التحديثات
1. عدّل النظام داخل Claude كالمعتاد.
2. حمّل آخر نسخة من `index.html` (اطلبها من Claude) واستبدل بها الملف هنا.
3. `git add index.html CHANGELOG.md && git commit -m "وصف التعديل" && git push`

## استعادة النظام من المستودع
افتح محادثة جديدة مع Claude، أرفق `index.html` واطلب "انشر هذا الملف كتطبيق" ثم استورد النسخة الاحتياطية من الإعدادات.
